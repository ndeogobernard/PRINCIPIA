02
OPEN SOURCE

PRINCIPIA — open tools for fiber networks

PRINCIPIA is an independently developed open-source ecosystem focused on the design, documentation and exchange of structured fiber-optic network data.

The project explores how fiber infrastructure information can move between geographical information systems, engineering drawings and database-backed applications without unnecessarily losing network semantics.

PRINCIPIA for QGIS

An open-source QGIS plugin for designing and documenting FTTH, GPON and FTTx networks directly in a geospatial environment. Its focus includes structured network elements, fiber infrastructure documentation and data interchange.

GitHub repository  ·  QGIS Plugin Repository

PRINCIPIA Designer

A web-based application for fiber-network design and management, using structured network information and a PostGIS-backed data model. Its development includes interoperability workflows for exchanging network data with CAD environments.

PRINCIPIA CAD

An AutoCAD add-in extending fiber-optic network documentation workflows into the CAD environment, complementing the broader PRINCIPIA ecosystem.

principia.example  ·  GitHub  ·  PRINCIPIA on LinkedIn

Research, publications and conferences

RIPE SEE 14  /  APRIL 2026

The Documentation Trap

Turning Fibre Maps into Operational Data (Lessons from QGIS and PRINCIPIA Workflows).

Presented at RIPE SEE 14, this talk discussed the limitations of traditional fiber-network documentation, the importance of structured geospatial information, explicit relationships between network elements and the transition from visual maps to operational network data.

View conference presentation

TELFOR 2026  /  ACCEPTED PAPER

Recovering Connectivity from Geometry-Only CAD Interchange

A Derivable Spacing Bound for Fiber Outside-Plant Round-Trip

This research investigates the preservation of fiber-network semantics through DXF interchange and the reconstruction of network connectivity from drawing geometry.

The proposed approach uses DXF extended entity data (XDATA), controlled layer naming and bounding-box endpoint matching. A mathematical proposition establishes sufficient conditions for exact connectivity recovery independently of entity scan order.

The method is evaluated using synthetic network fixtures, real-world symbol footprints and randomized adversarial configurations.

Accepted for TELFOR 2026. The demonstrated round trip is PRINCIPIA-native and is not claimed to provide universal CAD/GIS interoperability.

05
NEXT RESEARCH

Towards vendor-neutral fiber network interoperability

The next proposed research direction is the development of an open-source, vendor-neutral interoperability framework for exchanging structured fiber-network designs across CAD, GIS and OSS platforms.

Instead of creating separate converters between every pair of applications, the proposed approach introduces a Canonical Intermediate Model (CIM), with format-specific import and export adapters.

SOURCECAD / GIS / OSS / database systems
IMPORTSource-specific adapter
CORECanonical Intermediate Model
EXPORTDestination-specific adapter
OUTPUTConverted network data and fidelity report

Loss-aware conversion

A central objective is to distinguish information that is preserved, transformed, reconstructed, approximated or lost during conversion.

The proposed model would separate geometry, topology, fiber-level connectivity, semantics, identity and provenance, enabling conversions to be evaluated using reproducible fidelity metrics.

PROPOSED RESEARCH TITLE

Canonical Intermediate Model for Loss-Aware Interchange of Fiber Network Designs Across CAD, GIS and OSS Platforms

Research concept and planned development. This is not a completed or validated universal conversion engine.
