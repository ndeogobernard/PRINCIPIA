PRINCIPIA BRAND KIT  v1.0  (November 2026)
==========================================

Start with PRINCIPIA-Brand-Guidelines.pdf: it explains which logo to use,
clear space, minimum sizes, colors, fonts and what not to do.

01-Logo/       Primary-Logo (default), Symbol (icons and avatars), Name-Only (rare)
               Each in: color, reversed (for dark backgrounds), black, white
               Formats: SVG (master vector), PDF and EPS (vector, for print and
               Illustrator), PNG (transparent, three sizes)
02-App-Icon-and-Favicon/
               App icon (rounded and square), favicon.ico/.svg/.png,
               apple-touch-icon, web manifest, HTML snippet
03-Colors/     Brand palette as CSS and JSON (HEX, RGB, approximate CMYK)
04-Fonts/      Space Grotesk and Inter, free under the SIL Open Font License

File names: PRINCIPIA-[version]-[color].[format]
Never place the Symbol next to the logo or the name: that shows the P twice.
Lettering is converted to outlines; always use these files, never retype the logo.
